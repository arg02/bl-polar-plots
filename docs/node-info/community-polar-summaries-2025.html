Community polar plot summaries — 2025

Suggested plain-English readings of the 2025 openair polar plots for Bloomberg Philanthropies community / cultural nodes (no EndDate). Descriptions are derived from the same hourly data used to draw the plots (sensor pollution + Marylebone Road MY1 wind).

How to read these. Distance from the centre is wind speed; angle is where the wind came from; colour is concentration. A hot centre usually means higher levels in calm air (local build-up / poor dispersion). A hot lobe toward the outer ring in one direction can mean a contribution from that direction that shows more clearly in stronger winds.

Caveat. Wind is from MY1 (central London), not a local mast at each node, so directional hints are approximate and shared meteorology can make calm-weather peaks look similar across sites. Treat each summary as a draft for review, not a definitive source attribution.

Colour scale notes (for next plot batch)

Each plot currently normalises its colour scale to roughly its own high end (about the 90th percentile, capped at 55 µg/m³ for NO₂ and 30 for PM₂.₅). Across this set that high end ranged from about 34–55 µg/m³ for NO₂ and 11–23 for PM₂.₅ — so two plots can look equally “hot” even when absolute levels differ a lot. That is good for seeing shape at one node; it is poor for comparing intensity between nodes.

A shared scale (e.g. 0–55 for NO₂, 0–25 for PM₂.₅, or 0–max across the network) would make quieter sites look flatter and busier sites look hotter — which is honest for cross-site comparison, but can make low-pollution patterns harder to read. A practical middle ground is a shared scale per pollutant, with the numeric colour bar always visible so “pale” does not look like “no signal”.

Current scale (problem)

openair defaultuses red cols = "default"

Cool → warm, but the top is red/magenta — easy to read as “over the limit” even when the value is only high relative to that plot.

Suggested alternatives (cool → warmer, without a red top)

These are all available via openair’s cols argument (or a short custom hex vector). Prefer perceptually even scales so steps in concentration look even.

Viridisrecommended cols = "viridis"

Purple → teal → yellow. Colourblind-friendly, print-safe, clearly “more” without implying exceedance. Strong default pick for public AQ graphics.

Cividisrecommended cols = "cividis"

Navy → grey-olive → yellow. Designed for CVD accessibility; very restrained “heat” at the top.

Magma (light end) cols = "magma"

Near-black → purple → peach → cream. No traffic-light red; the high end is pale, which can feel counter-intuitive unless the key is labelled clearly.

Plasma cols = "plasma"

Blue → magenta → amber → yellow. Energetic “hotter” feel; still avoids classic alert red, though magenta can feel strong on lavender page backgrounds.

BuPu (sequential) cols = "BuPu"

Ice → lilac → deep purple. Fits Breathe London’s blue/lavender brand; high end is purple, not red. Lower contrast than viridis for busy polar lobes.

PuBuGn cols = "PuBuGn"

Pale → blue → teal-green. Soft and on-brand; high end is deep teal rather than “alarm”.

Custom BL amber cols = c("#e0e0ff","#88b0c8","#088476","#c4a035","#8a6a12")

Lavender → teal → gold/amber. Cool-to-warm using BL chart teal and a restrained amber top — reads as intensity, not “limit breached”.

Also available but less ideal here

Heat / jet / turbored top

Classic rainbow/heat scales. Easy to misread against AQ “red = exceedance” conventions — better avoided for public community pages.

Practical suggestion: try viridis or cividis first with a shared NO₂ / PM₂.₅ limit across all community plots; if brand alignment matters more, use the custom lavender→teal→amber vector. Happy to regenerate a small comparison strip (same node, several palettes) when you want to pick one.
