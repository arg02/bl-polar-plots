How to read the wind

Polar plots

2025

A year of pollution, drawn by the wind

70%

This plot shows how pollution measured at this node relates to wind speed and direction over the course of a year. It is centred on the node location. Switch NO2 / PM2.5 to see the difference.

  • Direction — where the wind came from (N, S, E, W).
  • Circles — these show wind speed in metres per second, increasing from the middle outwards.
  • Colour — average concentrations recorded for that wind speed and direction.

What this plot suggests

The plot is shown on a map, centred on the node for context. Warmer colours show the direction that this node detects pollution from, not that pollution is concentrated only at this point.
