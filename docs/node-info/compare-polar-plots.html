Notes

  • Co-location: CLDP0016 is co-located at the MY1 reference station site, which is why we can use MY1 wind data for the CLDP0016 plot.
  • Sensor Closure: CLDP0016 closed on 14 December 2024, so data ends on 13 December.
  • Data Matching: Wind data from MY1 was matched with CLDP0016 pollution data by hour-beginning timestamps.
  • Plot Interpretation: The radius represents wind speed (m/s), and the angle represents wind direction. Colors indicate NO2 concentration levels.
  • Comparison: Both sensors are at the same location, so differences in the plots reflect differences in sensor characteristics, calibration, or measurement methodology.
