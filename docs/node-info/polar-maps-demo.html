Polar Maps Demo

Using openairmaps::polarMap() to display polar plots on maps

1. Static Map

A static PNG map created using polarMap(static = TRUE). This uses ggplot2 and can be saved as an image file.

Status: Generating... (Check server/polar-maps-demo.html for results)

Static map will appear here once generated.
File: server/my1-polar-map-static.png

polarMap( data = my1_data, pollutant = "no2", x = "ws", latitude = "latitude", longitude = "longitude", provider = "osm", static = TRUE )

2. Dynamic Map (Interactive Leaflet)

An interactive Leaflet map created using polarMap(static = FALSE). Users can zoom, pan, and interact with the map.

Status: Generating... (Check server/polar-maps-demo.html for results)

Interactive map will appear here once generated.
File: server/my1-polar-map-dynamic.html

polarMap( data = my1_data, pollutant = "no2", x = "ws", latitude = "latitude", longitude = "longitude", provider = "OpenStreetMap", static = FALSE )

3. Multiple Sites Map

A map showing multiple sensors (MY1 and CLDP0016) with separate layers. Users can toggle between sites using the layer control.

Status: Generating... (Check server/polar-maps-demo.html for results)

Multiple sites map will appear here once generated.
File: server/multi-site-polar-map.html

polarMap( data = multi_data, pollutant = "no2", type = "site", # Creates separate layer for each site latitude = "latitude", longitude = "longitude", limits = "fixed", # Same color scale static = FALSE )

Key Features

Automatic Georeferencing

  • No manual distance calculations
  • Proper coordinate handling
  • Accurate positioning

Interactive Maps

  • Zoom and pan
  • Click markers for info
  • Layer controls

Multiple Sites

  • Compare sensors
  • Toggle layers
  • Shared color scales

Customizable

  • Color schemes
  • Marker sizes
  • Base maps

How to Generate Maps

To generate these maps, run:

cd server Rscript create-polar-maps.R

Note: If you encounter architecture errors, you may need to reinstall packages:

# Fix architecture issues install.packages(c("xml2", "yaml", "htmltools", "farver", "scales"), type = "source")
