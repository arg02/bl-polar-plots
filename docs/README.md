# Co-Located Sensor Comparisons - 2025

## View Online

Published via GitHub Pages from this `docs/` folder on branch `reference-comparison`
(Settings → Pages → Deploy from a branch → `/docs`):

`https://arg02.github.io/bl-polar-plots/`

The Vite node-info mockup is separate; see the root README section **Deploying the node mockup**.

## Local Viewing

To view locally:
1. Clone this repository
2. Open `index.html` in your web browser
3. All images and pages are included with relative paths

## Contents

- **index.html** - Master page listing all sensors with Intro and Methodology sections
- Individual comparison pages for each sensor (NO2, PM2.5, Combined)
- All PNG images (polar plots and time series graphs)
- R code boxes showing the `polarPlot()` calls used

## Data

- **Year:** 2025
- **Reference Stations:** Imperial College stations
- **Wind Data:** MY1 (Marylebone Road AURN station)
- **Color Scale:** 90th percentile limits to reduce outlier influence

## Notes

- All files use relative paths - keep the folder structure intact
- No external dependencies required
- Works offline once downloaded
