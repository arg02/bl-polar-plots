Co-Located Sensor Comparisons - 2025

Introduction

This page presents polar plot comparisons between Breathe London (BL) sensors and their co-located Imperial College reference stations for 2025. Polar plots visualize pollutant concentrations as a function of wind speed and direction, helping identify pollution sources and their directional patterns.

Each comparison shows side-by-side polar plots for the Imperial reference station and the BL sensor, using common wind data to ensure fair comparison. Time series graphs below show the temporal relationship between measurements.

Methodology

Sensor Selection

BL sensors were identified using the /ListSensors API endpoint, filtering for sensors with SiteLocationType: "Co-Location". This identified 17 co-located sensors across London.

Data Availability

For each co-located sensor, we checked 2025 data availability using the /getClarityData endpoint for January 2025 (744 hourly records expected). Sensors with sufficient data (≥100 matched records) were included in the analysis.

Reference Station Matching

BL sensors were matched to Imperial College reference stations using:

  • Location name matching: Comparing BL sensor site names with Imperial station names
  • Geographic proximity: For sensors without exact name matches, finding the nearest Imperial station (typically <1km for co-located sensors)
  • Manual verification: Special cases (e.g., CLDP0013 uses BX1 for NO2 and BQ9 for PM2.5) were verified manually

Data Processing

  • Pollution data: Imperial station data from openair::importImperial(), BL sensor data from Breathe London API
  • Wind data: Common wind speed and direction from MY1 (Marylebone Road AURN station) via openair::importAURN() - Imperial stations don't provide wind data directly
  • Timestamp matching: Data matched by hour-beginning timestamps (both APIs use hour-beginning convention)
  • Outlier handling: Color scales use 90th percentile limits (capped at 55 µg/m³ for NO2, 30 µg/m³ for PM2.5) to prevent extreme outliers from dominating the visualization

Visualization

Polar plots generated using openair::polarPlot() with:

  • Common color scale limits for fair comparison
  • Wind speed (m/s) on radial axis, wind direction (°) on angular axis
  • Mean pollutant concentration shown as color intensity

Time series graphs show temporal patterns with lines breaking at missing data points.
