Co-Located Sensor Comparisons — 2025

Side-by-side polar plots of Breathe London sensors and their Imperial College reference stations, using shared wind data so directional patterns can be compared fairly.

Introduction

Polar plots show pollutant concentration as a function of wind speed and direction. They help identify nearby sources (hot centres in calm air) versus contributions arriving on stronger winds from a particular direction.

Each comparison below pairs an Imperial reference station with its co-located Breathe London sensor for 2025.

Methodology

  • BL sites with SiteLocationType: "Co-Location"
  • Matched hours via hour-beginning timestamps
  • Wind from MY1 (Marylebone Road AURN) — Imperial stations do not supply wind
  • Colour limits use the 90th percentile (capped at 55 µg/m³ NO₂, 30 µg/m³ PM₂.₅)

Reading the plots

In each pair, the left plot is the Imperial reference and the right is the BL sensor. Both use the same wind and the same colour scale for that pollutant.

Time series for each pollutant sit under the polar plots. Links under each card open the full detail page with the polarPlot() call used.
